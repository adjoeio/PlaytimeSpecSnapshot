# PlaytimeSpecSnapshot

CocoaPods spec repo for the pre-release (beta) versions of adjoe's Playtime SDK and RewardsConnect SDK for iOS. Stable releases are in https://github.com/adjoeio/PlaytimeSpecExternal.

## Using a beta

Add this source to your Podfile next to your existing sources:

    source 'https://github.com/adjoeio/PlaytimeSpecSnapshot.git'

Then pin the beta version of PlaytimeSDK or RewardsConnectSDK.

An automated release process adds the specs here, so do not edit them by hand.
